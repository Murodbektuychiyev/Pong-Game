# Pong Game: AI vs Player

Bu loyiha – JavaScript/React asosida brauzerda ishlaydigan klassik Pong o‘yinidir. O‘yinda AI va Player raqobatlashadi, mode tanlash (easy, normal, hard) va boshqa funksiyalar mavjud.

## Foydalanish

1. Brauzerda `index.html` faylini oching.
2. Ism, ochko va mode tanlang, o‘yinni boshlang!
3. O‘rtada yashil setka chiziqli maydon, responsive dizayn, localStorage’da ism va mode saqlanadi.
